# 通信費インデックス（tsushinhi-index）

日本の通信費（光回線・格安SIM）の**料金と条件を毎日自動で記録し続ける公開データセット**です。

各社の料金は頻繁に変わりますが、**「いつ・いくらから・いくらに変わったのか」を横断的に記録した公開データは存在しません。**
このリポジトリはその空白を埋めることを目的にしています。

## なぜ作るのか

光回線の実質的な負担額は、月額基本料だけでは決まりません。

- キャッシュバックの**額と受取時期**
- 適用に必要な**必須オプション**
- 工事費の**実負担額**と途中解約時の残債
- 契約期間

これらの組み合わせで決まりますが、**各社が自社に有利な計算で「実質料金」を出している**ため、横並びの比較が成立していません。
さらにこれらは頻繁に変わります（実測: ある事業者の料金ページは**年59回**内容が変わっていました）。

**このデータセットは、全社を同一の計算式に通した「実質月額」を毎日記録します。**

## 実質月額の計算式

```
実質月額 =
  ( 月額基本料 × 契約月数
  + 工事費の実負担額
  + 事務手数料
  + 必須オプション費用 × 加入必要月数
  - キャッシュバック額
  - その他割引の総額
  ) ÷ 契約月数
```

**計算ルール**

- 契約月数は各社の標準契約期間。**36ヶ月に正規化した値も併記**します
- キャッシュバックは**受取時期が契約期間を超える分は算入しません**（受け取れない可能性があるため）
- 必須オプション（キャッシュバック適用に加入が必要なもの）は費用に**算入**します。任意オプションは算入しません
- **値が取得できなかった項目は推定しません。** `null` を入れ、実質月額も `null` にします

最後のルールが最も重要です。**欠損を推定で埋めた時点で、このデータは信用に値しなくなります。**

## データの扱い方針

- **出典URLと取得日時を全レコードに記録**します
- **取得に失敗したとき、前回の値を引き継ぎません。** 失敗は失敗として記録します
- 収集対象は**各社が一般に公開している情報のみ**です。ログインが必要な情報は収集しません
- **自動アクセスを望まない意思表示があるサイトは対象にしません。** robots.txt での禁止に加え、bot対策で保護されているサイトも、技術的に回避できるかどうかに関わらず除外しています
- 収集するのは**料金・日数・条件といった事実値のみ**で、説明文などの表現をそのまま複製・再掲することはしません
- 相手サーバーに負荷をかけないよう、アクセスは低頻度・直列で行います

## 収集元

`collect/targets.json` に、対象事業者と参照しているURLをすべて記載しています。

収集は2系統で行います。

| 系統 | 対象 | 取れるもの |
|---|---|---|
| **主: お知らせ監視** | 各社公式の「料金改定のお知らせ」ページ | **正式な適用日・変更理由** |
| 従: 料金ページ監視 | 料金・キャンペーンページ | 実際の掲載値 |

お知らせを主系統にしているのは、料金ページの差分だけでは「気づいた日」しか分からず、**正式な改定日と変更理由が取れない**ためです。

検討中。

## 免責

このデータは正確性を期して自動収集していますが、**契約前には必ず各社の公式サイトで最新の条件をご確認ください。**
各レコードには出典URLと取得日時が記録されています。
